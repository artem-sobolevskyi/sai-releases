## Get it

1. Open the **[latest release](https://github.com/artem-sobolevskyi/jujune-releases/releases/latest)**.
2. Download `Jujune.exe`.
3. Run it. No installer.

Source, docs, and how the diagnostics work: **[artem-sobolevskyi/jujune-internet-tester](https://github.com/artem-sobolevskyi/jujune-internet-tester)**.

Builds are published from GitHub Actions whenever the source repo ships a new version.
